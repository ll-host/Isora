# Isora — product contract

## Назначение

Isora управляет локальными QEMU-машинами через графический интерфейс и CLI. Основная рабочая платформа — Arch Linux с системным libvirt/KVM. Поддержка Windows остаётся в кодовой базе, но не является текущей целью разработки и выпуска.

## Поддерживаемый выпуск

- Единственный публикуемый бинарный артефакт — `isora-<pkgver>-1-x86_64.pkg.tar.zst`.
- Единственный поддерживаемый способ установки релиза — `sudo pacman -U <пакет>`.
- Пакет собирается локально на Arch Linux через `./isora.sh`.
- GitHub не собирает, не тестирует и не упаковывает проект.
- В `ll-host/Isora` всегда остаётся ровно один актуальный Release; предыдущие Releases и связанные теги удаляются при публикации нового.
- В Release вручную загружается только pacman-пакет. Автоматические GitHub-ссылки на исходники являются частью интерфейса GitHub.

## Инварианты продукта

- Isora не подключает физические диски, host devices, общие каталоги или сетевые диски автоматически.
- Импортированный внешний QCOW2 проверяется и не удаляется вместе с записью машины.
- ISO подключается read-only.
- Виртуальный диск можно только увеличивать и только у остановленной машины.
- Резервная копия становится видимой только после завершения и проверки.
- Linux backend использует `qemu:///system`, storage pool `isora` и каталог `/var/lib/libvirt/images/isora`.
- Windows backend остаётся компилируемым и использует прямой запуск QEMU/WHPX без libvirt.

## Готовность релиза

Релиз готов, когда локально собранный пакет:

1. успешно читается `pacman -Qp`;
2. содержит `/usr/bin/isora`, `/usr/bin/isoractl` и desktop entry;
3. устанавливается через `sudo pacman -U`;
4. запускает GUI и CLI на целевой Arch-системе;
5. не ломает создание, запуск, остановку, snapshots и backups;
6. опубликован как единственный GitHub Release с единственным загруженным `.pkg.tar.zst`.

## Версия

Единственный источник версии — `VERSION.txt`. Предрелизные версии содержат суффикс `alpha`, `beta` или `rc` и публикуются как GitHub prerelease.
