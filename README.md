# Isora

Isora — менеджер локальных QEMU/KVM-машин с интерфейсом на QML/Qt Quick в стиле Material 3 Dark. Основная платформа разработки и выпуска — Arch Linux. Код прямого QEMU/WHPX backend для Windows сохраняется, но официальные релизы сейчас предназначены только для Arch Linux.

Текущая версия: **0.1.0-alpha2**.

## Возможности

- отдельные QCOW2-диски и изолированные каталоги машин;
- импорт ISO с SHA-256 и обнаружением дубликатов;
- создание, запуск, обычное и принудительное выключение;
- настройка RAM/vCPU и безопасное увеличение диска выключенной машины;
- snapshots и независимые резервные копии с проверкой SHA-256;
- QEMU/KVM, libvirt и SPICE/virt-viewer на Linux;
- сохранённый QEMU/WHPX backend для Windows;
- оконный, безрамочный и полноэкранный режимы;
- проверка новых версий через [GitHub Releases](https://github.com/ll-host/Isora/releases);
- CLI `isoractl` (`IsoraCLI.exe` на Windows).

## Установка на Arch Linux

Единственный поддерживаемый способ установки и тестирования релиза:

```bash
sudo pacman -U ./isora-<версия>-1-x86_64.pkg.tar.zst
```

В GitHub Releases публикуется только готовый `.pkg.tar.zst`, собранный локально. GitHub дополнительно показывает автоматически создаваемые ссылки на архивы исходников.

Пакет устанавливает `isora`, `isoractl`, desktop entry и значок. При установке включаются обычные и read-only сокеты `virtqemud` и `virtstoraged`, а также обязательные для запуска машин службы журналирования `virtlogd` и блокировок `virtlockd`.

Зависимости: Qt 6.8+, libvirt, QEMU, virt-viewer; для UEFI рекомендуется `edk2-ovmf`.

## Локальная разработка

Запустите цифровое меню:

```bash
./isora.sh
```

Меню умеет:

1. собрать Arch-пакет в `dist/`;
2. удалить прежние GitHub Releases и опубликовать единственный актуальный пакет;
3. скачать через `curl` последний опубликованный пакет из GitHub Releases в домашнюю папку и установить его через `sudo pacman -U`;
4. добавить все изменения, запросить сообщение коммита и выполнить commit + push;
5. подтянуть изменения через `git pull --rebase`;
6. показать состояние Git, релизов и локальных пакетов;
7. собрать отладочную версию и запустить локальные тесты;
8. собрать приложение и сохранить снимок интерфейса для визуальной проверки.

Сборка выполняется только на локальном Arch-компьютере. GitHub Actions и удалённая сборка не используются.

Перед публикацией меню проверяет, что рабочее дерево чистое, локальная `main` совпадает с `origin/main`, пакет соответствует `VERSION.txt`, а `origin` указывает на `ll-host/Isora`. Новый релиз сначала загружается как draft, затем старые релизы и их теги удаляются, после чего новый релиз публикуется.

## Данные

Системный storage pool Isora расположен в `/var/lib/libvirt/images/isora`. Программа изменяет только созданные или явно подключённые пользователем данные. ISO подключается read-only, уменьшение виртуального диска запрещено.

## Windows

Windows backend остаётся в исходниках и использует QEMU/WHPX, QMP и отдельное SDL-окно гостя. Windows-сборки не создаются и не публикуются текущим Arch-релизным процессом.
